공공·교육 도메인에서 **3년 이상** 시스템 개발부터 운영까지 경험한 웹 개발자입니다.

최근에는 대학 내부 연구비 시스템과 국가 연구비통합관리시스템 간 **통합연계모듈 개발**을 담당해 청주대·대전대 **2개 대학**에 적용했습니다.
인터페이스 DB 기반의 **배치 연계 + 실시간 API 연계**를 구축해 과제·협약·연구비 집행·카드·전자증빙 데이터를 자동 연동하고, 검증 테스트부터 운영 전환까지 수행했습니다.

그 전에는 교육이력관리시스템을 유지보수했고, 2023년부터 2년 동안은 동물용의약품 정보관리시스템을 **재구축 → 고도화**하며 민원 화면을 신규 개발하고 SR/CS 이슈를 **누적 1,000건+** 분석·대응했습니다.

AI 코딩 도구 도입 검증을 맡아, **시나리오·E2E 시험**으로 결함 유형을 분류하고 프롬프트 사용 가이드를 정리했습니다.

안정적인 운영과 꼼꼼한 검증으로, 사용자와 운영자 모두 편하게 쓸 수 있는 서비스를 만드는 것이 목표입니다.
